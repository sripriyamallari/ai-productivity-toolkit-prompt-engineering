# 🤖 AI Productivity Toolkit – Prompt Engineering

AI Productivity Toolkit is a Python-based project that demonstrates practical Prompt Engineering techniques and AI-assisted productivity workflows using Hugging Face Transformers and FLAN-T5.

## 📌 Project Overview

This project demonstrates how different Prompt Engineering techniques can be used to perform common AI productivity tasks such as text summarization, classification, text generation, coding assistance, debugging, email generation, resume assistance, and research assistance.

## ⚙️ How It Works

1. Load the FLAN-T5 AI model.
2. Create different Prompt Engineering examples.
3. Apply zero-shot and few-shot prompting.
4. Use roles, context, instructions, and constraints.
5. Generate structured AI outputs.
6. Perform different AI productivity tasks.

## 🎯 Prompt Engineering Techniques

### Zero-shot Prompting
The AI performs a task without being given examples.

### Few-shot Prompting
The AI is provided with examples before performing the task.

### Role-based Prompting
A specific role is assigned to the AI, such as a career advisor or research assistant.

### Context-based Prompting
Relevant background information is provided to improve the response.

### Instructions and Constraints
Specific instructions and limitations are provided to control the output.

### Structured Output
Information can be generated in a structured format such as JSON.

## 📊 Prompt Evaluation

The project includes reusable prompt templates and a prompt testing report. Different prompts are tested based on expected keywords and task requirements to understand their effectiveness.
